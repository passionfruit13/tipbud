# TipBud — Server Tip Tracker

**Official site: https://tipbud.app** — [Support](https://tipbud.app/support) · [Privacy](https://tipbud.app/privacy) · [U.S. tip deduction guide](https://tipbud.app/tip-deduction) · [Press kit](https://tipbud.app/press)

TipBud logs a shift in about ten seconds and shows tipped workers their True Rate — wages + tips − tip-outs. For iPhone. No ads, no account, no subscription.

This repository hosts a legacy alias of the site; the canonical home is [tipbud.app](https://tipbud.app).
